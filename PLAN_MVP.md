# Futbolito MVP

## Objetivo
Crear una primera versión usable de Futbolito para organizar partidos semanales entre amigos, sin construir todo de una vez.

## Versión 1 debe permitir
- Ver próximo partido.
- Confirmar asistencia: Voy, Reserva o Me bajo.
- Ver nómina de confirmados, reservas y bajas.
- Agregar galletas.
- Armar equipos Naranjo/Azul.
- Registrar resultado final.
- Guardar historial básico de partidos.
- Calcular tabla básica Naranjo vs Azul.

## Fuera de la versión 1
- Fotos.
- Comentarios.
- Votaciones.
- Ranking avanzado de jugadores.
- Morosidad avanzada.
- Asado avanzado.
- Notificaciones automáticas.
- Login complejo.

## Stack recomendado
- React/Vite.
- Supabase para base de datos.
- Vercel para publicar.
- GitHub para versiones.

## Regla de avance
Cambio pequeño → probar preview → build → commit → push.
