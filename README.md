# Futbolito App Prototipo — Respaldo base

Checkpoint generado para respaldar la versión actual y subirla a GitHub.

## Qué contiene este respaldo
- `CHECKPOINT.md`: resumen funcional y visual de la versión actual.
- `github-pasos.md`: pasos simples para crear el repositorio y subir el respaldo.
- `src/App.jsx`: archivo base placeholder para iniciar el repositorio React.
- `package.json`: base para proyecto Vite + React.

## Nota importante
El código visual completo sigue estando en el canvas de ChatGPT: **Futbolito App Prototipo**.

Este paquete sirve para:
1. Crear el repositorio en GitHub ahora.
2. Tener un checkpoint externo.
3. Dejar estructura lista para reemplazar `src/App.jsx` por el código completo del canvas.

## Recomendación
Después de descargar este ZIP:
1. Súbelo a GitHub como primer commit.
2. Luego copiamos el código completo del canvas a `src/App.jsx`.
3. Creamos commits por avance: dashboard, próximo partido, partidos, cuotas, ranking, reglas, asado.
